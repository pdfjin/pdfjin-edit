# 📄 pdfjin-edit

> Add text, shapes, and whiteout visual edits to PDF documents by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-edit.svg)](https://pypi.org/project/pdfjin-edit/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/edit-pdf.html](https://pdfjin.com/pages/edit-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-edit
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-edit.git
cd pdfjin-edit
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-edit --help
```

Use in Python:
```python
import pdfjin_edit
```

---

## 🧪 Testing

```bash
pip install pytest
pytest
```
